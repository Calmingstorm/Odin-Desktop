# Security policy

## Supported versions

Security fixes are supported for **1.0.x**. Use the latest available patch release
in that series. Development snapshots and older series are not supported releases.

## Report a vulnerability privately

Use GitHub's **Report a vulnerability** for this repository:
[Private vulnerability report](https://github.com/Calmingstorm/Odin-Desktop/security/advisories/new).
Do not disclose an unpatched vulnerability in a public issue or PR.

Include:

- The exact app version, package format (`.deb` or AppImage), distribution and desktop session.
- A description of the vulnerability, prerequisites, expected behavior and observed impact.
- Minimal reproduction steps using synthetic data, with sanitized errors or logs if relevant.
- Whether the issue affects the local engine, managed SSH, integrations, computer use or packaging.

Leave out credentials, API tokens, private keys, complete profiles or databases, private conversations,
personal files and identifying host details. Do not test against another person's installation or
live service without permission. Preserve uncertain outcomes rather than repeating harmful actions.

Reports are reviewed privately. This policy does not promise a response or remediation deadline.
